1. Struttura del progetto

acchiappa-il-quadrato/ ├── package.json dati del progetto, dipendenze (express, ws) e script "npm start" ├── server.js SERVER: Express (HTTP) + WebSocket (ws) + logica del gioco ├── public/ │ └── index.html CLIENT: pagina del gioco (HTML + CSS + JavaScript) ├── musica/ │ └── sottofondo.wav musica inviata in streaming dalla rotta GET /musica └── node_modules/ moduli installati da "npm install" (non si consegna)

2. Architettura

Il browser chiede la pagina con una normale richiesta HTTP (Express la serve dalla cartella public). Poi lo script della pagina apre un WebSocket verso lo stesso server e la stessa porta. Da quel momento client e server si scambiano messaggi JSON in tempo reale.

3. I messaggi scambiati (protocollo)

Ogni messaggio è un oggetto JSON con un campo tipo, che dice a chi lo riceve cosa fare.

DirezionetipoContenutoQuando
Server → un clientbenvenuto{ tipo, id, colore, puntiPerVincere }appena il client si collega
Client → servernome{ tipo, nome }il giocatore preme Gioca
Server → tuttiquadrato{ tipo, numero, x, y }ogni 1,2 s (setInterval)
Client → serverclick{ tipo, numero }il giocatore preme sul quadrato
Server → tuttipreso{ tipo, numero, id, nome, colore }primo click valido
Server → tutticlassifica{ tipo, connessi, giocatori[] }entra/esce qualcuno, cambia un punteggio
Server → tuttivittoria{ tipo, id, nome, colore, secondi }qualcuno arriva a 10 punti
Server → tuttinuova_partita{ tipo }5 s dopo la vittoria (setTimeout)
Una partita, passo per passo.
  1. Il browser apre la pagina e il WebSocket → il server crea l'id e manda benvenuto.
  2. Il giocatore scrive il nome → nome → il server manda a tutti la classifica.
  3. Ogni 1,2 s il server sceglie una posizione e la manda a tutti → quadrato.
  4. Un giocatore preme il quadrato → click → il server controlla che sia il primo → +1 punto → preso + classifica a tutti.
  5. Qualcuno arriva a 10 → vittoria → pausa di 5 s → nuova_partita.

§ 3 Stato del gioco

let contatoreId = 0;
let quadrato = { numero: 0, x: 0, y: 0, preso: true };
let inPausa = false;

Il server è l'unico arbitro: conserva lui lo stato della partita (quale quadrato è in campo, se è già stato preso, se siamo in pausa). I client non decidono niente: mostrano solo quello che arriva dal server. Così nessuno può "barare" modificando la pagina nel browser.

quadrato.numero cresce a ogni nuova posizione: serve a scartare i click arrivati in ritardo su un quadrato che ormai si è già spostato.

§ 4 Express: middleware, rotte e avvio del server HTTP

const app = express();

app.use((req, res, next) => {
    console.log(`[HTTP] ${req.method} ${req.url}`);
    next();
});

app.use(express.static(path.join(__dirname, 'public')));

app.get('/musica', (req, res) => {
    const fileMusica = path.join(__dirname, 'musica', 'sottofondo.wav');
    if (fs.existsSync(fileMusica)) {
        const info = fs.statSync(fileMusica);
        res.writeHead(200, { 'Content-Type': 'audio/wav', 'Content-Length': info.size });
        fs.createReadStream(fileMusica).pipe(res);
    } else {
        res.status(404).send('Musica non trovata');
    }
});

app.get('/api/classifica', (req, res) => {
    res.json({ connessi: ws_server.clients.size, puntiPerVincere: PUNTI_PER_VINCERE, giocatori: listaClassifica() });
});

app.use((req, res) => {
    res.status(404).send('Pagina non trovata');
});

const server = app.listen(PORTA, () => {
    console.log(`Server avviato! Apri nel browser: http://localhost:${PORTA}`);
    indirizziRete().forEach((ip) => {
        console.log(`Dagli altri PC della rete:   http://${ip}:${PORTA}`);
    });
});

Middleware: funzione (req, res, next) eseguita per ogni richiesta, nell'ordine in cui è scritta. Il nostro logger stampa la richiesta e chiama next() per passare al successivo. Se non chiamasse next() né rispondesse, il browser resterebbe in attesa per sempre.

express.static('public') serve in automatico i file della cartella public: quando il browser chiede / riceve index.html. Il prof usava res.sendFile('/index.html', { root: __dirname }): il risultato è lo stesso.

Rotta GET /musica: invia il file audio in streaming. fs.createReadStream() legge il file a pezzi (chunk) e .pipe(res) li manda subito al browser, senza caricare tutto il file in memoria. writeHead imposta codice 200 e intestazioni (Content-Type, Content-Length).

Rotta GET /api/classifica: con res.json() restituisce lo stato della partita in JSON (provare ad aprire localhost:3000/api/classifica).

L'ultimo middleware risponde 404: viene raggiunto solo se nessuna rotta prima ha risposto. app.listen() avvia il server e restituisce l'oggetto server HTTP, che passiamo al WebSocket.

§ 5 Server WebSocket ed eventi

const ws_server = new Server({ server });

ws_server.on('connection', (ws) => {
    contatoreId++;
    ws.id = contatoreId;
    ws.colore = COLORI[(ws.id - 1) % COLORI.length];
    ws.nome = null;
    ws.punti = 0;
    console.log(`[WS] nuovo client connesso, id: ${ws.id}`);

    ws.send(JSON.stringify({ tipo: 'benvenuto', id: ws.id, colore: ws.colore, puntiPerVincere: PUNTI_PER_VINCERE }));
    inviaClassifica();

    ws.on('message', (dati) => {
        let msg;
        try {
            msg = JSON.parse(dati);
        } catch (errore) {
            console.log(`[WS] messaggio non valido da ${ws.id}`);
            return;
        }

        if (msg.tipo === 'nome') {
            const nomePulito = String(msg.nome).trim().substring(0, 15);
            ws.nome = nomePulito || `Giocatore ${ws.id}`;
            console.log(`[WS] il client ${ws.id} si chiama "${ws.nome}"`);
            inviaClassifica();
        }

        if (msg.tipo === 'click') {
            if (!ws.nome || inPausa || quadrato.preso || msg.numero !== quadrato.numero) return;
            quadrato.preso = true;
            ws.punti++;
            console.log(`[GIOCO] ${ws.nome} prende il quadrato n.${quadrato.numero} (${ws.punti} punti)`);
            inviaATutti({ tipo: 'preso', numero: quadrato.numero, id: ws.id, nome: ws.nome, colore: ws.colore });
            inviaClassifica();

            if (ws.punti >= PUNTI_PER_VINCERE) {
                inPausa = true;
                console.log(`[GIOCO] *** ${ws.nome} ha vinto la partita! ***`);
                inviaATutti({ tipo: 'vittoria', id: ws.id, nome: ws.nome, colore: ws.colore, secondi: PAUSA_VITTORIA_MS / 1000 });
                setTimeout(nuovaPartita, PAUSA_VITTORIA_MS);
            }
        }
    });

    ws.on('close', () => {
        console.log(`[WS] client disconnesso, id: ${ws.id}`);
        inviaClassifica();
    });

    ws.on('error', (errore) => {
        console.log(`[WS] errore sul client ${ws.id}: ${errore.message}`);
    });
});

new Server({ server }) aggancia il WebSocket al server HTTP: stessa porta 3000. Il browser apre il WebSocket con una richiesta HTTP speciale (intestazione Upgrade: websocket); il server risponde 101 Switching Protocols e da lì la connessione resta aperta in entrambe le direzioni (full-duplex).

  • connection: un nuovo client. Gli diamo id, colore, nome e punti salvandoli dentro l'oggetto ws (come ws.id = quale dell'esempio 04), gli mandiamo il benvenuto con ws.send() (solo a lui) e a tutti la classifica.
  • message: un messaggio di quel client. Lo convertiamo con JSON.parse dentro un try/catch (un testo non valido non deve far crashare il server) e in base al campo tipo gestiamo nome o click.
  • close: il client se n'è andato; ws lo ha già tolto da ws_server.clients, quindi rimandiamo la classifica aggiornata.
  • error: gestire l'errore evita che il programma si fermi.

Chi vince il click? Node.js esegue il nostro codice su un solo thread (event loop): i messaggi vengono gestiti uno alla volta, in ordine di arrivo. Il primo click valido mette quadrato.preso = true, quindi i click successivi vengono scartati dall'if.

Negli esempi del prof: ws_socket_03 (on message), ws_socket_04/05 (ws.id), ws_socket_06/07 (JSON in arrivo), ws_socket_08 (close + numero connessi)

§ 6 Ciclo di gioco

setInterval(() => {
    if (inPausa) return;
    if (ws_server.clients.size === 0) return;
    nuovaPosizione();
}, INTERVALLO_MS);

setInterval richiama la funzione ogni 1200 ms. È il server che "spinge" (push) i dati ai client senza che li chiedano: è proprio quello che con HTTP normale non si può fare. Se siamo in pausa o non c'è nessuno collegato, la funzione esce subito con return.

Negli esempi del prof: ws_socket_00 → 04 (setInterval + invio a tutti)

§ 7 Funzioni di supporto

function inviaATutti(messaggio) {
    const testo = JSON.stringify(messaggio);
    ws_server.clients.forEach((client) => {
        if (client.readyState === client.OPEN) client.send(testo);
    });
}

function listaClassifica() {
    const lista = [];
    ws_server.clients.forEach((client) => {
        if (client.nome) lista.push({ id: client.id, nome: client.nome, colore: client.colore, punti: client.punti });
    });
    lista.sort((a, b) => b.punti - a.punti);
    return lista;
}

function inviaClassifica() {
    inviaATutti({ tipo: 'classifica', connessi: ws_server.clients.size, giocatori: listaClassifica() });
}

function nuovaPosizione() {
    quadrato.numero++;
    quadrato.x = Math.floor(Math.random() * 101);
    quadrato.y = Math.floor(Math.random() * 101);
    quadrato.preso = false;
    inviaATutti({ tipo: 'quadrato', numero: quadrato.numero, x: quadrato.x, y: quadrato.y });
}

function nuovaPartita() {
    ws_server.clients.forEach((client) => {
        client.punti = 0;
    });
    inPausa = false;
    console.log('[GIOCO] nuova partita!');
    inviaATutti({ tipo: 'nuova_partita' });
    inviaClassifica();
}

function indirizziRete() {
    const indirizzi = [];
    const interfacce = os.networkInterfaces();
    for (const nome in interfacce) {
        for (const info of interfacce[nome]) {
            if (info.family === 'IPv4' && !info.internal) indirizzi.push(info.address);
        }
    }
    return indirizzi;
}
  • inviaATutti: è il broadcast. Scorre ws_server.clients con forEach e manda il messaggio a ogni client con la connessione OPEN. L'oggetto viene convertito in testo con JSON.stringify una sola volta.
  • listaClassifica: costruisce un array con i giocatori che hanno un nome e lo ordina con sort((a, b) => b.punti - a.punti) (decrescente).
  • nuovaPosizione: coordinate casuali da 0 a 100 = percentuale dello spazio. Ogni client le trasforma in pixel secondo la grandezza del suo schermo.
  • nuovaPartita: azzera i punti; viene chiamata da setTimeout (una volta sola, dopo 5 secondi).
  • indirizziRete: con os.networkInterfaces() trova l'IP del PC per farlo vedere nel terminale (serve per giocare da altri PC). Usa for...in (chiavi di un oggetto) e for...of (elementi di un array).

Negli esempi del prof: ws_socket_00 → 08 (clients.forEach + send), ws_socket_08 (array dei client)

La pagina ha: un'intestazione (nome, connessi, stato, musica), il campo con il quadrato, la classifica (lista <ol> riempita da JavaScript), due schermate sovrapposte (nome iniziale e vittoria, mostrate/nascoste aggiungendo o togliendo la classe CSS nascosto) e l'elemento <audio> che prende la musica dalla rotta /musica del server. Il CSS (dentro <style>) serve solo alla grafica.

Icone vettoriali (SVG). All'inizio del body c'è un contenitore <svg> invisibile con 9 <symbol>: ognuno è un'icona disegnata una sola volta (bersaglio, utenti, altoparlante acceso/spento, trofeo, stella, fulmine, play, avviso). Dove serve un'icona scriviamo <svg class="icona"><use href="#i-trofeo"/></svg>: <use> "copia" il simbolo indicato. Essendo vettoriali restano nitide a qualsiasi grandezza e prendono il colore dal CSS (stroke: currentColor). Per cambiare icona da JavaScript basta cambiare l'attributo href con setAttribute (pulsante della musica e fumetto dei messaggi). Lo stile delle icone è quello del set open source Lucide (licenza ISC).

§ 4 Eventi del WebSocket

webSocket.onopen = () => {
    stato.textContent = 'Connesso';
    pallinoStato.className = 'pallino-stato verde';
    pulsanteEntra.disabled = false;
    inputNome.focus();
};

webSocket.onclose = () => {
    stato.textContent = 'Disconnesso';
    pallinoStato.className = 'pallino-stato rosso';
    quadrato.style.display = 'none';
    mostraMessaggio('Connessione persa: ricarica la pagina', 'avviso');
};

webSocket.onmessage = (event) => {
    const msg = JSON.parse(event.data);

    if (msg.tipo === 'benvenuto') {
        mioId = msg.id;
        pallinoMio.style.background = msg.colore;
        mioNome.textContent = 'Giocatore ' + msg.id;
        puntiPerVincere = msg.puntiPerVincere;
        obiettivo.textContent = msg.puntiPerVincere;
    } else if (msg.tipo === 'quadrato') {
        numeroQuadrato = msg.numero;
        const spazioX = campo.clientWidth - quadrato.offsetWidth;
        const spazioY = campo.clientHeight - quadrato.offsetHeight;
        quadrato.style.left = (spazioX * msg.x / 100) + 'px';
        quadrato.style.top = (spazioY * msg.y / 100) + 'px';
        quadrato.style.backgroundColor = '';
        quadrato.classList.remove('preso');
        quadrato.style.display = 'block';
    } else if (msg.tipo === 'preso') {
        if (msg.numero !== numeroQuadrato) return;
        quadrato.classList.add('preso');
        quadrato.style.backgroundColor = msg.colore;
        if (msg.id === mioId) mostraMessaggio('+1 per te!', 'stella');
        else mostraMessaggio(msg.nome + ' è stato più veloce', 'fulmine');
    } else if (msg.tipo === 'classifica') {
        connessi.textContent = 'Connessi: ' + msg.connessi;
        aggiornaClassifica(msg.giocatori);
    } else if (msg.tipo === 'vittoria') {
        quadrato.style.display = 'none';
        testoVittoria.textContent = msg.id === mioId ? 'Hai vinto!' : 'Ha vinto ' + msg.nome;
        testoVittoria.style.color = msg.colore;
        schermataVittoria.classList.remove('nascosto');
        avviaContoAllaRovescia(msg.secondi);
    } else if (msg.tipo === 'nuova_partita') {
        schermataVittoria.classList.add('nascosto');
        clearInterval(timerConto);
        mostraMessaggio('Nuova partita! Via!', 'play');
    }
};
  • onopen: connessione pronta, abilitiamo il pulsante Gioca.
  • onclose: server spento o rete persa, avvisiamo il giocatore.
  • onmessage: il testo ricevuto diventa oggetto con JSON.parse; il campo tipo decide cosa fare (benvenuto, quadrato, preso, classifica, vittoria, nuova_partita).

Posizione del quadrato: spazio disponibile = dimensione del campo − dimensione del quadrato; pixel = spazio × percentuale / 100. Così il quadrato resta sempre dentro il campo, anche sul telefono.

addEventListener collega una funzione a un evento. Sul quadrato usiamo pointerdown, che scatta appena si preme (mouse o dito): più rapido di click. Il client non assegna punti: manda solo { tipo: 'click', numero } e decide il server. audio.play() restituisce una Promise; con .catch() gestiamo il caso in cui il browser blocchi l'audio.

§ 6 Funzioni

function entraInPartita() {
    if (webSocket.readyState !== WebSocket.OPEN) return;
    const nome = inputNome.value.trim();
    webSocket.send(JSON.stringify({ tipo: 'nome', nome: nome }));
    if (nome) mioNome.textContent = nome;
    schermataNome.classList.add('nascosto');
}

function aggiornaClassifica(giocatori) {
    classifica.innerHTML = '';
    giocatori.forEach((giocatore, indice) => {
        const riga = document.createElement('li');
        if (giocatore.id === mioId) riga.classList.add('io');
        const posizione = creaElemento('span', 'posizione', indice + 1 + '.');
        const colore = creaElemento('span', 'colore', '');
        colore.style.background = giocatore.colore;
        const nome = creaElemento('span', 'nome', giocatore.nome);
        const barra = creaElemento('span', 'barra', '');
        const riempimento = document.createElement('div');
        riempimento.style.width = (giocatore.punti / puntiPerVincere * 100) + '%';
        riempimento.style.background = giocatore.colore;
        barra.appendChild(riempimento);
        const punti = creaElemento('span', 'punti', giocatore.punti);
        riga.append(posizione, colore, nome, barra, punti);
        classifica.appendChild(riga);
    });
}

function creaElemento(tag, classe, testo) {
    const elemento = document.createElement(tag);
    elemento.className = classe;
    elemento.textContent = testo;
    return elemento;
}

function mostraMessaggio(testo, icona) {

    clearTimeout(timerMessaggio);

function avviaContoAllaRovescia(secondi) {
    conto.textContent = secondi;
    clearInterval(timerConto);
    timerConto = setInterval(() => {
        secondi--;
        conto.textContent = Math.max(secondi, 0);
    }, 1000);
}

7. Domande probabili all'interrogazione

1. Che differenza c'è tra HTTP e WebSocket?In HTTP è sempre il client a fare una richiesta e il server risponde, poi la comunicazione finisce. Il WebSocket è una connessione persistente e bidirezionale (full-duplex): resta aperta e anche il server può inviare dati quando vuole, come la posizione del quadrato ogni 1,2 secondi.
2. Come fanno HTTP e WebSocket a usare la stessa porta?Il WebSocket parte come una richiesta HTTP con l'intestazione Upgrade: websocket. Il server (ws, agganciato al server di Express con new Server({ server })) risponde 101 Switching Protocols e da quel momento la connessione diventa WebSocket.
3. Cos'è un middleware? A cosa serve next()?È una funzione (req, res, next) che Express esegue per ogni richiesta, nell'ordine in cui è registrata. Può rispondere oppure chiamare next() per passare la richiesta al middleware/rotta successivo. Esempi nel nostro codice: logger, express.static, 404.
4. Perché non consegnate la cartella node_modules?Perché si ricrea con npm install: il package.json elenca le dipendenze (express e ws) con le versioni. Così lo zip è leggero.
5. Come fate il broadcast?Il server ws tiene l'insieme dei client in ws_server.clients: lo scorriamo con forEach e chiamiamo client.send() su ognuno (funzione inviaATutti).
6. Perché usate JSON e il campo "tipo"?Il WebSocket trasporta testo: con JSON.stringify trasformiamo un oggetto in testo, con JSON.parse facciamo il contrario. Il campo tipo dice a chi riceve che messaggio è e quindi cosa deve fare.
7. Se due giocatori cliccano quasi insieme, chi prende il punto?Quello il cui messaggio arriva prima al server. Node gestisce gli eventi uno alla volta (event loop su un solo thread): il primo click mette quadrato.preso = true e i successivi vengono ignorati. Il numero del quadrato evita che vengano contati click su un quadrato vecchio.
8. Perché è il server a decidere i punti e non il client?Perché il codice del client si può modificare dal browser: se decidesse il client si potrebbe barare. Il server è l'unico arbitro, i client mostrano solo lo stato.
9. Come assegnate id e colore ai giocatori?Alla connessione incrementiamo contatoreId e lo salviamo in ws.id. Il colore è COLORI[(id - 1) % COLORI.length]: l'operatore modulo fa ripartire l'array quando i colori finiscono.
10. Cosa succede quando un giocatore chiude la pagina?Scatta l'evento close: ws lo toglie da ws_server.clients e noi rimandiamo a tutti la classifica, così sparisce dalla lista e il numero di connessi scende.
11. Cos'è uno stream e perché lo usate per la musica?È un flusso di dati letto a pezzi. fs.createReadStream() legge il file un pezzo alla volta e pipe(res) lo invia mentre legge: non serve caricare tutto il file in memoria.
12. Differenza tra setInterval e setTimeout?setInterval ripete la funzione ogni N millisecondi (movimento del quadrato); setTimeout la esegue una sola volta dopo N millisecondi (nuova partita dopo 5 s). Si fermano con clearInterval / clearTimeout.
13. Perché le coordinate sono in percentuale?Ogni giocatore può avere uno schermo diverso (PC, telefono). Il server manda 0-100 e ogni client la trasforma in pixel in base alla grandezza del suo campo.
14. Perché textContent e non innerHTML per i nomi?Con innerHTML un nome contenente codice HTML verrebbe interpretato (rischio XSS); textContent lo mostra sempre come semplice testo.
15. Cosa succederebbe senza il try/catch?Se arrivasse un messaggio non in formato JSON, JSON.parse lancerebbe un errore non gestito e il server si fermerebbe per tutti i giocatori.
16. Come si gioca da un altro PC?Tutti sulla stessa rete; dagli altri PC si apre http://IP-del-server:3000. L'IP lo stampa il server all'avvio grazie al modulo os. Il firewall deve permettere le connessioni a Node.js.
