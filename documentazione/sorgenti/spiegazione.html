2. Architettura

Il browser chiede la pagina con una normale richiesta HTTP (Express la serve dalla cartella public). Poi lo script della pagina apre un WebSocket verso lo stesso server e la stessa porta. Da quel momento client e server si scambiano messaggi JSON in tempo reale.

3. I messaggi scambiati (protocollo)

Ogni messaggio è un oggetto JSON con un campo tipo, che dice a chi lo riceve cosa fare. "Sfida" = solo i giocatori della sfida; "un client" = solo chi gioca da solo.

DirezionetipoContenutoQuando

Client → servernome{ tipo, nome }il giocatore preme Continua

Client → serveresci{ tipo }preme Menu

Server → sfida / un clientpreso{ tipo, numero, id, nome, colore, guadagno }click valido
Server → un clientmancato{ tipo, numero, vite }il tempo è scaduto: −1 vita
Server → un clientlivello{ tipo, livello, colore }ogni 10 quadrati (infinita)
Server → un clientstato_partita{ tipo, vite, viteMax, punti, presi, livello, mancanti, ... }dopo ogni cambiamento della partita singola
Server → un clientgame_over{ tipo, punti, presi, livello, posizione }vite finite
Server → tutticlassifica{ tipo, connessi, giocatori[] }entra/esce qualcuno, cambia un punteggio della sfida
Server → sfidavittoria{ tipo, id, nome, colore, secondi }qualcuno arriva a 10 punti
Server → sfidanuova_partita{ tipo }5 s dopo la vittoria
Una partita singola (Difficoltà o Infinita), passo per passo.
  1. Il client manda nome, poi modalita → il server crea ws.partita e manda stato_partita.
  2. Il server manda quadrato (con durata) e avvia un setTimeout.
  3. Click in tempo → click → clearTimeout, punti → preso (+ livello ogni 10) + stato_partita → nuovo quadrato.
  4. Tempo scaduto → mancato, −1 vita. A 0 vite → game_over; se è un record, record a tutti.

§ 5 Server WebSocket ed eventi

const ws_server = new Server({ server });

ws_server.on('connection', (ws) => {
    contatoreId++;
    ws.id = contatoreId;
    ws.colore = COLORI[(ws.id - 1) % COLORI.length];
    ws.nome = null;
    ws.modalita = null;
    ws.punti = 0;
    ws.partita = null;
    console.log(`[WS] nuovo client connesso, id: ${ws.id}`);

    inviaA(ws, { tipo: 'benvenuto', id: ws.id, colore: ws.colore, puntiPerVincere: PUNTI_PER_VINCERE, difficolta: DIFFICOLTA });
    inviaA(ws, { tipo: 'record', record: record.elenco() });
    inviaClassifica();

    ws.on('message', (dati) => {
        let msg;
        try {
            msg = JSON.parse(dati);
        } catch (errore) {
            console.log(`[WS] messaggio non valido da ${ws.id}`);
            return;
        }

        if (msg.tipo === 'nome') {
            const nomePulito = String(msg.nome).trim().substring(0, 15);
            ws.nome = nomePulito || `Giocatore ${ws.id}`;
            console.log(`[WS] il client ${ws.id} si chiama "${ws.nome}"`);
        }

        if (msg.tipo === 'modalita') {
            if (!ws.nome) return;
            fermaPartita(ws);
            if (msg.modalita === 'sfida') {
                ws.modalita = 'sfida';
                ws.punti = 0;
            } else if (msg.modalita === 'difficolta' && Object.keys(DIFFICOLTA).includes(msg.difficolta)) {
                ws.modalita = 'difficolta';
                iniziaPartitaSingola(ws, 'difficolta', msg.difficolta);
            } else if (msg.modalita === 'infinita') {
                ws.modalita = 'infinita';
                iniziaPartitaSingola(ws, 'infinita', null);
            }
            console.log(`[WS] ${ws.nome} gioca in modalità ${ws.modalita}${msg.difficolta ? ' (' + msg.difficolta + ')' : ''}`);
            inviaClassifica();
        }

        if (msg.tipo === 'click') {
            if (ws.modalita === 'sfida') clickSfida(ws, msg.numero);
            else clickSingolo(ws, msg.numero);
        }

        if (msg.tipo === 'esci') {
            fermaPartita(ws);
            ws.modalita = null;
            inviaClassifica();
        }
    });

    ws.on('close', () => {
        fermaPartita(ws);
        console.log(`[WS] client disconnesso, id: ${ws.id}`);
        inviaClassifica();
    });

    ws.on('error', (errore) => {
        console.log(`[WS] errore sul client ${ws.id}: ${errore.message}`);
    });
});

new Server({ server }) aggancia il WebSocket al server HTTP: stessa porta 3000. Il browser chiede l'Upgrade: websocket, il server risponde 101 Switching Protocols e la connessione resta aperta in entrambe le direzioni.

  • connection: salviamo nell'oggetto ws id, colore, nome, modalità (null = nel menu), punti della sfida e partita singola; mandiamo a lui benvenuto e record, a tutti la classifica.
  • message: JSON.parse dentro try/catch, poi in base a tipo: nome, modalita (sceglie Sfida, Difficoltà o Infinita), click (smistato a clickSfida o clickSingolo), esci (torna al menu).
  • La difficoltà ricevuta viene controllata con Object.keys(DIFFICOLTA).includes(...): accettiamo solo facile, difficile o impossibile.
  • close: fermaPartita(ws) annulla i timer della partita singola, poi aggiorniamo la classifica. error: gestito per non bloccare il server.

§ 7 Funzioni di invio e della sfida

function inviaA(ws, messaggio) {
    if (ws.readyState === ws.OPEN) ws.send(JSON.stringify(messaggio));
}

function inviaATutti(messaggio) {
    const testo = JSON.stringify(messaggio);
    ws_server.clients.forEach((client) => {
        if (client.readyState === client.OPEN) client.send(testo);
    });
}

function giocatoriSfida() {
    return Array.from(ws_server.clients).filter((client) => client.modalita === 'sfida');
}

function inviaASfida(messaggio) {
    giocatoriSfida().forEach((client) => inviaA(client, messaggio));
}

function listaClassifica() {
    const lista = giocatoriSfida().map((client) => ({ id: client.id, nome: client.nome, colore: client.colore, punti: client.punti }));
    lista.sort((a, b) => b.punti - a.punti);
    return lista;
}

function inviaClassifica() {
    inviaATutti({ tipo: 'classifica', connessi: ws_server.clients.size, giocatori: listaClassifica() });
}

function nuovaPosizione() {
    quadrato.numero++;
    quadrato.x = Math.floor(Math.random() * 101);
    quadrato.y = Math.floor(Math.random() * 101);
    quadrato.preso = false;
    inviaASfida({ tipo: 'quadrato', numero: quadrato.numero, x: quadrato.x, y: quadrato.y, dimensione: DIMENSIONE_SFIDA, colore: null });
}

function clickSfida(ws, numero) {
    if (inPausa || quadrato.preso || numero !== quadrato.numero) return;
    quadrato.preso = true;
    ws.punti++;
    console.log(`[SFIDA] ${ws.nome} prende il quadrato n.${quadrato.numero} (${ws.punti} punti)`);
    inviaASfida({ tipo: 'preso', numero: quadrato.numero, id: ws.id, nome: ws.nome, colore: ws.colore });
    inviaClassifica();
    if (ws.punti >= PUNTI_PER_VINCERE) {
        inPausa = true;
        console.log(`[SFIDA] *** ${ws.nome} ha vinto la sfida! ***`);
        inviaASfida({ tipo: 'vittoria', id: ws.id, nome: ws.nome, colore: ws.colore, secondi: PAUSA_VITTORIA_MS / 1000 });
        setTimeout(nuovaSfida, PAUSA_VITTORIA_MS);
    }
}

function nuovaSfida() {
    giocatoriSfida().forEach((client) => { client.punti = 0; });
    inPausa = false;
    console.log('[SFIDA] nuova sfida!');
    inviaASfida({ tipo: 'nuova_partita' });
    inviaClassifica();
}
  • inviaA(ws, msg): invia a un solo client. inviaATutti(msg): broadcast a tutti con ws_server.clients.forEach.
  • giocatoriSfida(): Array.from trasforma il Set dei client in array e filter tiene solo quelli con modalita === 'sfida'. inviaASfida manda il messaggio solo a loro: chi gioca da solo o è nel menu non riceve il quadrato della sfida.
  • listaClassifica: map trasforma i client in oggetti semplici, sort li ordina per punti.
  • clickSfida: Node gestisce i messaggi uno alla volta (event loop): il primo click mette quadrato.preso = true e i successivi vengono scartati. A 10 punti: vittoria e setTimeout(nuovaSfida, 5000).

Negli esempi del prof: ws_socket_00 → 08 (clients.forEach + send), ws_socket_08 (array dei client)

§ 8 Partite singole: Difficoltà e Infinita

function iniziaPartitaSingola(ws, modalita, difficolta) {
    const conf = modalita === 'difficolta' ? DIFFICOLTA[difficolta] : null;
    const vite = conf ? conf.vite : VITE_INFINITA;
    ws.partita = {
        modalita: modalita,
        difficolta: difficolta,
        vite: vite,
        viteMax: vite,
        punti: 0,
        presi: 0,
        livello: 1,
        numero: 0,
        preso: true,
        timer: null,
        finita: false,
    };
    inviaStato(ws);
    ws.partita.timer = setTimeout(() => prossimoQuadrato(ws), 800);
}

function parametriInfinita(livello) {
    const tempo = Math.max(380, Math.round(1500 * Math.pow(0.88, livello - 1)));
    const dimensione = Math.max(34, 76 - (livello - 1) * 4);
    const colore = COLORI_LIVELLO[(livello - 1) % COLORI_LIVELLO.length];
    return { tempo, dimensione, colore };
}

function prossimoQuadrato(ws) {
    const p = ws.partita;
    if (!p || p.finita) return;
    const param = p.modalita === 'difficolta' ? DIFFICOLTA[p.difficolta] : parametriInfinita(p.livello);
    p.numero++;
    p.preso = false;
    inviaA(ws, {
        tipo: 'quadrato',
        numero: p.numero,
        x: Math.floor(Math.random() * 101),
        y: Math.floor(Math.random() * 101),
        dimensione: param.dimensione,
        colore: param.colore || null,
        durata: param.tempo,
    });
    p.timer = setTimeout(() => quadratoScaduto(ws), param.tempo);
}

function quadratoScaduto(ws) {
    const p = ws.partita;
    if (!p || p.preso || p.finita) return;
    p.preso = true;
    p.vite--;
    inviaA(ws, { tipo: 'mancato', numero: p.numero, vite: p.vite });
    inviaStato(ws);
    if (p.vite <= 0) {
        finePartita(ws);
        return;
    }
    p.timer = setTimeout(() => prossimoQuadrato(ws), PAUSA_QUADRATO_MS * 2);
}

function clickSingolo(ws, numero) {
    const p = ws.partita;
    if (!p || p.finita || p.preso || numero !== p.numero) return;
    p.preso = true;
    clearTimeout(p.timer);
    p.presi++;
    let guadagno = 1;
    const livelloPrima = p.livello;
    if (p.modalita === 'infinita') {
        guadagno = PUNTI_BASE * p.livello;
        p.livello = Math.floor(p.presi / QUADRATI_PER_LIVELLO) + 1;
    }
    p.punti += guadagno;
    inviaA(ws, { tipo: 'preso', numero: p.numero, id: ws.id, nome: ws.nome, colore: ws.colore, guadagno: guadagno });
    if (p.livello > livelloPrima) {
        inviaA(ws, { tipo: 'livello', livello: p.livello, colore: parametriInfinita(p.livello).colore });
        console.log(`[INFINITA] ${ws.nome} sale al livello ${p.livello}`);
    }
    inviaStato(ws);
    p.timer = setTimeout(() => prossimoQuadrato(ws), PAUSA_QUADRATO_MS);
}

function finePartita(ws) {
    const p = ws.partita;
    p.finita = true;
    clearTimeout(p.timer);
    const classifica = p.modalita === 'infinita' ? 'infinita' : p.difficolta;
    const posizione = record.aggiungi(classifica, {
        nome: ws.nome,
        punti: p.punti,
        livello: p.livello,
        presi: p.presi,
        data: new Date().toLocaleDateString('it-IT'),
    });
    console.log(`[GAME OVER] ${ws.nome} (${classifica}): ${p.punti} punti, livello ${p.livello}`);
    inviaA(ws, { tipo: 'game_over', modalita: p.modalita, difficolta: p.difficolta, punti: p.punti, presi: p.presi, livello: p.livello, posizione: posizione });
    if (posizione >= 0) inviaATutti({ tipo: 'record', record: record.elenco() });
}

function fermaPartita(ws) {
    if (!ws.partita) return;
    clearTimeout(ws.partita.timer);
    ws.partita = null;
}

function inviaStato(ws) {
    const p = ws.partita;
    inviaA(ws, {
        tipo: 'stato_partita',
        modalita: p.modalita,
        difficolta: p.difficolta,
        vite: p.vite,
        viteMax: p.viteMax,
        punti: p.punti,
        presi: p.presi,
        livello: p.livello,
        mancanti: QUADRATI_PER_LIVELLO - (p.presi % QUADRATI_PER_LIVELLO),
        perLivello: QUADRATI_PER_LIVELLO,
        colore: p.modalita === 'infinita' ? parametriInfinita(p.livello).colore : null,
    });
}

Ogni client ha la sua partita, salvata in ws.partita (vite, punti, quadrati presi, livello, numero del quadrato, timer). Il ciclo è fatto di setTimeout:

  • prossimoQuadrato: manda solo a quel client il quadrato con posizione, dimensione, colore e durata, poi avvia un timer di durata ms.
  • Se il timer scade prima del click scatta quadratoScaduto: −1 vita, messaggio mancato; a 0 vite finePartita.
  • clickSingolo: se il numero è giusto e il quadrato è aperto, clearTimeout annulla il timer (niente vita persa), aggiunge punti e prepara il quadrato successivo.

Formula di Tetris (modalità infinita). Ogni quadrato vale 40 × livello punti, come una riga singola in Tetris. Il livello è Math.floor(presi / 10) + 1: si sale ogni 10 quadrati. parametriInfinita(livello) calcola la difficoltà: tempo 1500 × 0,88livello−1 ms (minimo 380), lato 76 − 4 × (livello − 1) px (minimo 34), colore preso dall'array con l'operatore %. Esempio: 25 quadrati = 10 × 40 + 10 × 80 + 5 × 120 = 1800 punti, livello 3.

finePartita salva il risultato con record.aggiungi(); se è un nuovo record lo manda a tutti (inviaATutti), così la lista si aggiorna in tempo reale anche per gli altri.

Negli esempi del prof: ws_socket_03 (click → server), ws_socket_00 → 04 (timer lato server)

§ 9 Altre funzioni

function indirizziRete() {
    const indirizzi = [];
    const interfacce = os.networkInterfaces();
    for (const nome in interfacce) {
        for (const info of interfacce[nome]) {
            if (info.family === 'IPv4' && !info.internal) indirizzi.push(info.address);
        }
    }
    return indirizzi;
}

indirizziRete: con os.networkInterfaces() trova l'IP del PC per mostrarlo nel terminale (serve per giocare da altri PC). Usa for...in (chiavi di un oggetto) e for...of (elementi di un array).

5. Il modulo dei record — record.js

MODULO Un modulo scritto da noi

const fs = require('fs');
const path = require('path');

const FILE_RECORD = path.join(__dirname, 'record.json');
const MAX_RECORD = 5;

let record = strutturaVuota();

function strutturaVuota() {
    return { facile: [], difficile: [], impossibile: [], infinita: [] };
}

function carica() {
    try {
        const testo = fs.readFileSync(FILE_RECORD, 'utf8');
        record = Object.assign(strutturaVuota(), JSON.parse(testo));
        console.log('[RECORD] record caricati da record.json');
    } catch (errore) {
        record = strutturaVuota();
        console.log('[RECORD] nessun record salvato: si parte da zero');
    }
}

function aggiungi(classifica, risultato) {
    if (risultato.punti <= 0) return -1;
    const lista = record[classifica];
    lista.push(risultato);
    lista.sort((a, b) => b.punti - a.punti);
    const posizione = lista.indexOf(risultato);
    record[classifica] = lista.slice(0, MAX_RECORD);
    if (posizione >= MAX_RECORD) return -1;
    salva();
    return posizione;
}

function salva() {
    const testo = JSON.stringify(record, null, 2);
    fs.writeFile(FILE_RECORD, testo, (errore) => {
        if (errore) console.log('[RECORD] errore nel salvataggio: ' + errore.message);
    });
}

function elenco() {
    return record;
}

module.exports = { carica, aggiungi, elenco };

Un modulo è un file JavaScript che esporta qualcosa con module.exports. Qui esportiamo carica, aggiungi ed elenco; salva e strutturaVuota restano private. In server.js basta const record = require('./record') e poi record.aggiungi(...).

  • carica: fs.readFileSync (sincrona, solo all'avvio) e JSON.parse dentro try/catch: se il file non c'è si parte con i record vuoti. Object.assign unisce la struttura vuota con i dati letti.
  • aggiungi: una partita con 0 punti non è un record e viene scartata subito (restituisce −1); altrimenti push, sort decrescente, indexOf per la posizione e slice(0, 5) per tenere i 5 migliori. Restituisce la posizione oppure −1.
  • salva: fs.writeFile è asincrona: il server non si blocca mentre scrive e la callback segnala eventuali errori. JSON.stringify(record, null, 2) scrive il JSON indentato.

webSocket.onopen = () => {
    stato.textContent = 'Connesso';

webSocket.onmessage = (event) => {
    const msg = JSON.parse(event.data);

    if (msg.tipo === 'benvenuto') {
        mioId = msg.id;
        pallinoMio.style.background = msg.colore;
        mioNome.textContent = 'Giocatore ' + msg.id;
        puntiPerVincere = msg.puntiPerVincere;
        obiettivo.textContent = msg.puntiPerVincere;
        configDifficolta = msg.difficolta;
        for (const chiave in configDifficolta) {
            const d = configDifficolta[chiave];
            document.getElementById('dettagli-' + chiave).textContent = d.vite + (d.vite === 1 ? ' vita' : ' vite') + ' · ' + (d.tempo / 1000).toLocaleString('it-IT') + ' s';
        }
    } else if (msg.tipo === 'quadrato') {
        numeroQuadrato = msg.numero;
        quadrato.style.width = msg.dimensione + 'px';
        quadrato.style.height = msg.dimensione + 'px';
        const spazioX = Math.max(0, campo.clientWidth - msg.dimensione);
        const spazioY = Math.max(0, campo.clientHeight - msg.dimensione);
        quadrato.style.left = (spazioX * msg.x / 100) + 'px';
        quadrato.style.top = (spazioY * msg.y / 100) + 'px';
        quadrato.style.backgroundColor = msg.colore || '';
        quadrato.style.setProperty('--bagliore', msg.colore || 'rgba(249, 202, 36, 0.55)');
        quadrato.classList.remove('preso');
        campo.classList.remove('errore');
        quadrato.style.display = 'block';
        if (msg.durata) avviaBarraTempo(msg.durata, msg.colore);
        else fermaBarraTempo();
    } else if (msg.tipo === 'preso') {
        if (msg.numero !== numeroQuadrato) return;
        quadrato.classList.add('preso');
        fermaBarraTempo();
        if (modalitaAttuale === 'sfida') quadrato.style.backgroundColor = msg.colore;
        if (msg.id === mioId) mostraMessaggio('+' + (msg.guadagno || 1) + (msg.guadagno > 1 ? ' punti' : ' per te!'), 'stella');
        else mostraMessaggio(msg.nome + ' è stato più veloce', 'fulmine');
    } else if (msg.tipo === 'mancato') {
        quadrato.style.display = 'none';
        fermaBarraTempo();
        campo.classList.remove('errore');
        void campo.offsetWidth;
        campo.classList.add('errore');
        mostraMessaggio('Mancato! Una vita in meno', 'cuore');
    } else if (msg.tipo === 'livello') {
        mostraMessaggio('Livello ' + msg.livello + '!', 'livello');
        campo.style.borderColor = msg.colore;
    } else if (msg.tipo === 'stato_partita') {
        aggiornaStato(msg);
    } else if (msg.tipo === 'game_over') {
        mostraGameOver(msg);
    } else if (msg.tipo === 'record') {
        record = msg.record;
        aggiornaRecord();
    } else if (msg.tipo === 'classifica') {
        connessi.textContent = 'Connessi: ' + msg.connessi;
        aggiornaClassifica(msg.giocatori);
    } else if (msg.tipo === 'vittoria') {
        quadrato.style.display = 'none';
        testoVittoria.textContent = msg.id === mioId ? 'Hai vinto!' : 'Ha vinto ' + msg.nome;
        testoVittoria.style.color = msg.colore;
        schermataVittoria.classList.remove('nascosto');
        avviaContoAllaRovescia(msg.secondi);
    } else if (msg.tipo === 'nuova_partita') {
        schermataVittoria.classList.add('nascosto');
        clearInterval(timerConto);
        mostraMessaggio('Nuova partita! Via!', 'play');
    }
};

onopen abilita il pulsante, onclose avvisa che la connessione è persa, onmessage converte il testo con JSON.parse e sceglie cosa fare in base a tipo:

  • quadrato: imposta grandezza, posizione (percentuale → pixel), colore e bagliore (variabile CSS --bagliore con setProperty); se c'è durata fa partire la barra del tempo.
  • preso, mancato (il campo "trema" con un'animazione CSS), livello (il bordo prende il colore del livello), stato_partita, game_over, record, classifica, vittoria, nuova_partita.

function entraInPartita() {
    if (webSocket.readyState !== WebSocket.OPEN) return;
    const nome = inputNome.value.trim();
    webSocket.send(JSON.stringify({ tipo: 'nome', nome: nome }));
    if (nome) mioNome.textContent = nome;
    schermataNome.classList.add('nascosto');
    schermataModalita.classList.remove('nascosto');
}

function scegliModalita(modalita, difficolta) {
    modalitaAttuale = modalita;
    difficoltaAttuale = difficolta;
    webSocket.send(JSON.stringify({ tipo: 'modalita', modalita: modalita, difficolta: difficolta }));
    schermataModalita.classList.add('nascosto');
    schermataGameover.classList.add('nascosto');
    pulsanteMenu.classList.remove('nascosto');
    pulisciCampo();
    pannelloSfida.classList.toggle('nascosto', modalita !== 'sfida');
    pannelloSolo.classList.toggle('nascosto', modalita === 'sfida');
    rigaLivello.classList.toggle('nascosto', modalita !== 'infinita');
    titoloModalita.textContent = modalita === 'infinita' ? 'Modalità infinita' : 'Difficoltà: ' + (configDifficolta[difficolta] ? configDifficolta[difficolta].nome : '');
    iconaModalita.setAttribute('href', modalita === 'infinita' ? '#i-infinito' : '#i-tachimetro');
    aggiornaRecord();
}

function tornaAlMenu() {
    webSocket.send(JSON.stringify({ tipo: 'esci' }));
    modalitaAttuale = null;
    pulisciCampo();
    pulsanteMenu.classList.add('nascosto');
    schermataGameover.classList.add('nascosto');
    schermataVittoria.classList.add('nascosto');
    schermataModalita.classList.remove('nascosto');
}

function pulisciCampo() {
    quadrato.style.display = 'none';
    numeroQuadrato = 0;
    fermaBarraTempo();
    campo.style.borderColor = '';
}

function aggiornaStato(dati) {
    let cuori = '';
    for (let i = 0; i < dati.viteMax; i++) {
        cuori += '<svg class="icona' + (i < dati.vite ? ' piena' : '') + '"><use href="#i-cuore"/></svg>';
    }
    vite.innerHTML = cuori;
    valorePunti.textContent = dati.punti;
    valorePresi.textContent = dati.presi;
    if (dati.modalita === 'infinita') {
        etichettaLivello.textContent = 'LIVELLO';
        valoreLivello.textContent = dati.livello;
        mancanti.textContent = dati.mancanti + (dati.mancanti === 1 ? ' quadrato' : ' quadrati');
        avanzamento.style.width = ((dati.perLivello - dati.mancanti) / dati.perLivello * 100) + '%';
        avanzamento.style.backgroundColor = dati.colore;
        campo.style.borderColor = dati.colore;
    } else {
        etichettaLivello.textContent = 'VITE';
        valoreLivello.textContent = dati.vite;
    }
}

function mostraGameOver(dati) {
    quadrato.style.display = 'none';
    finePunti.textContent = dati.punti;
    finePresi.textContent = dati.presi;
    fineLivello.textContent = dati.modalita === 'infinita' ? dati.livello : '-';
    testoRecord.textContent = dati.posizione >= 0 ? 'Nuovo record: ' + (dati.posizione + 1) + '° posto!' : '';

function aggiornaRecord() {
    const chiave = modalitaAttuale === 'infinita' ? 'infinita' : difficoltaAttuale;
    if (!chiave || !record[chiave]) return;
    titoloRecord.textContent = 'Record ' + (chiave === 'infinita' ? 'infinita' : configDifficolta[chiave].nome.toLowerCase());
    listaRecord.innerHTML = '';
    if (record[chiave].length === 0) {
        const riga = creaElemento('li', 'vuoto', 'Nessun record: sii il primo!');
        listaRecord.appendChild(riga);
    }
    record[chiave].forEach((r, indice) => {
        const riga = document.createElement('li');
        const posizione = creaElemento('span', 'posizione', indice + 1 + '.');
        const nome = creaElemento('span', 'nome', r.nome);
        const punti = creaElemento('span', 'punti', chiave === 'infinita' ? r.punti + ' (liv. ' + r.livello + ')' : r.punti);
        riga.append(posizione, nome, punti);
        listaRecord.appendChild(riga);
    });
}

function aggiornaClassifica(giocatori) {
    classifica.innerHTML = '';
    giocatori.forEach((giocatore, indice) => {
        const riga = document.createElement('li');
        if (giocatore.id === mioId) riga.classList.add('io');
        const posizione = creaElemento('span', 'posizione', indice + 1 + '.');
        const colore = creaElemento('span', 'colore', '');
        colore.style.background = giocatore.colore;
        const nome = creaElemento('span', 'nome', giocatore.nome);
        const barra = creaElemento('span', 'barra', '');
        const riempimento = document.createElement('div');
        riempimento.style.width = (giocatore.punti / puntiPerVincere * 100) + '%';
        riempimento.style.background = giocatore.colore;
        barra.appendChild(riempimento);
        const punti = creaElemento('span', 'punti', giocatore.punti);
        riga.append(posizione, colore, nome, barra, punti);
        classifica.appendChild(riga);
    });
}

function creaElemento(tag, classe, testo) {
    const elemento = document.createElement(tag);
    elemento.className = classe;
    elemento.textContent = testo;
    return elemento;
}

function avviaBarraTempo(durata, colore) {
    barraTempo.style.transition = 'none';
    barraTempo.style.width = '100%';
    barraTempo.style.backgroundColor = colore || '#f9ca24';
    void barraTempo.offsetWidth;
    barraTempo.style.transition = 'width ' + durata + 'ms linear';
    barraTempo.style.width = '0%';
}

function fermaBarraTempo() {
    barraTempo.style.transition = 'none';
    barraTempo.style.width = '0';
}

function mostraMessaggio(testo, icona) {
    testoMessaggio.textContent = testo;
    iconaMessaggio.setAttribute('href', '#i-' + icona);
    messaggio.classList.add('visibile');
    clearTimeout(timerMessaggio);
    timerMessaggio = setTimeout(() => messaggio.classList.remove('visibile'), 1500);
}

function avviaContoAllaRovescia(secondi) {
    conto.textContent = secondi;
    clearInterval(timerConto);
    timerConto = setInterval(() => {
        secondi--;
        conto.textContent = Math.max(secondi, 0);
    }, 1000);
}
  • scegliModalita manda { tipo: 'modalita' } e mostra il pannello giusto con classList.toggle(classe, condizione); tornaAlMenu manda esci.
  • aggiornaStato disegna i cuori (pieni = vite rimaste) e le statistiche in stile Tetris: punti, quadrati, livello e barra verso il prossimo livello.
  • mostraGameOver e aggiornaRecord: i nomi sono scritti con textContent, non innerHTML, così un nome con codice HTML non viene eseguito (protezione XSS).
  • avviaBarraTempo: la barra torna al 100% senza transizione, void barraTempo.offsetWidth obbliga il browser a ricalcolare, poi una transizione CSS la porta a 0% in esattamente durata millisecondi.
  • mostraMessaggio(testo, icona) sceglie l'icona con setAttribute('href', '#i-' + icona); setTimeout/clearTimeout gestiscono la durata.

8. Domande probabili all'interrogazione

1. Che differenza c'è tra HTTP e WebSocket?In HTTP è sempre il client a chiedere e il server risponde, poi la comunicazione finisce. Il WebSocket è una connessione persistente e bidirezionale (full-duplex): anche il server può inviare dati quando vuole, come i quadrati della sfida o il messaggio "mancato" allo scadere del tempo.
2. Come fanno HTTP e WebSocket a usare la stessa porta?Il WebSocket parte come una richiesta HTTP con l'intestazione Upgrade: websocket. Il server ws, agganciato a quello di Express con new Server({ server }), risponde 101 Switching Protocols e la connessione diventa WebSocket.
3. Cos'è un middleware? A cosa serve next()?È una funzione (req, res, next) che Express esegue per ogni richiesta, nell'ordine in cui è registrata. Può rispondere oppure chiamare next() per passare al successivo. Nel nostro codice: logger, express.static, 404.
4. Cos'è record.js e come lo usate?È un modulo scritto da noi. Esporta tre funzioni con module.exports = { carica, aggiungi, elenco } e server.js lo importa con require('./record'). Le funzioni non esportate (salva) restano private al modulo.
5. Perché readFileSync in un punto e writeFile nell'altro?readFileSync è sincrona: blocca finché il file è letto, ma la usiamo una volta sola all'avvio. writeFile è asincrona: il server continua a gestire i giocatori mentre scrive, e la callback avvisa quando ha finito o se c'è un errore.
6. Come funziona la modalità infinita?Come Tetris: ogni 10 quadrati presi (le "righe") si sale di livello, livello = Math.floor(presi / 10) + 1. Ogni quadrato vale 40 × livello punti. A ogni livello il tempo si moltiplica per 0,88 (−12%), il lato diminuisce di 4 px e il colore cambia.
7. Come fa ogni giocatore ad avere la sua partita?Lo stato è salvato in ws.partita, dentro l'oggetto della connessione di quel client, con il suo timer setTimeout. I messaggi della partita vanno solo a lui con inviaA(ws, ...).
8. Come si perde una vita?Quando il server manda un quadrato avvia un setTimeout di durata ms. Se il click arriva prima, clearTimeout annulla il timer; altrimenti scatta quadratoScaduto, che toglie una vita e manda mancato.
9. Cosa succede ai timer se il giocatore chiude la pagina?Nell'evento close chiamiamo fermaPartita(ws), che fa clearTimeout e cancella la partita: altrimenti i timer continuerebbero a girare per un client che non c'è più.
10. Come evitate che chi gioca da solo riceva il quadrato della sfida?Ogni client ha ws.modalita. giocatoriSfida() filtra i client con modalita === 'sfida' e inviaASfida manda i messaggi solo a loro.
11. Perché controllate la difficoltà con Object.keys(...).includes?Il messaggio arriva dal client e potrebbe contenere qualsiasi cosa. Accettiamo solo le chiavi facile, difficile, impossibile: un valore come constructor non deve essere preso per una difficoltà.
12. Se due giocatori della sfida cliccano quasi insieme, chi prende il punto?Quello il cui messaggio arriva prima: Node gestisce gli eventi uno alla volta (event loop su un solo thread). Il primo click mette quadrato.preso = true e gli altri vengono ignorati.
13. Perché è il server a decidere punti e vite?Perché il codice del client si può modificare dal browser: se decidesse il client si potrebbe barare. Il server è l'unico arbitro.
14. Cos'è uno stream e perché lo usate per la musica?Un flusso di dati letto a pezzi: fs.createReadStream() legge il file un pezzo alla volta e pipe(res) lo invia mentre legge, senza caricare tutto in memoria.
15. Perché textContent e non innerHTML per i nomi?Con innerHTML un nome contenente codice HTML verrebbe interpretato (rischio XSS); textContent lo mostra sempre come testo.
16. Come si gioca da un altro PC?Tutti sulla stessa rete; dagli altri PC si apre http://IP-del-server:3000. L'IP lo stampa il server all'avvio grazie al modulo os. Il firewall deve permettere le connessioni a Node.js.
